ONIT v0.23.0 — Collision Radar Private Pilot

Traffic-only private pilot.

Adds:
- Capacity states: Available / Busy / High Load / Collision Risk
- Collision Radar inside Traffic Control before assignment/release
- Safer-start recommendation when a selected teammate has a near deadline
- Lower-load alternative only among comparable role/department teammates
- Confirmation before releasing a brief when Collision Radar detects a high-risk overlap

No automatic reassignment. No employee productivity scoring. No backend changes required.
