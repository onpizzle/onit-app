# ONIT v0.31.0 — Core Intelligence

This frontend-only update implements the five approved hardening priorities:

1. Save / Sync architecture — protected local drafts, global unsaved/saving/saved states, offline protection and reload blocking while forms are dirty.
2. Traffic Command refinement — Queue, People, Timeline and Attention views.
3. Notification intelligence — Action Required vs Updates/FYI with Loud / Normal / Silent levels.
4. Cases Proof Engine — case readiness overview plus completed-work candidates that can start a linked Case draft.
5. Work Health — organisation and department workflow-health score; never an employee productivity score.

No Apps Script schema change is required for v0.31.0. It uses the existing v0.30.8 backend actions.
